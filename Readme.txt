ARIES PORTFOLIO — PROJECT GALLERY

Open index.html in a browser.

Each portfolio project has its own image folder:
images/project-01/
images/project-02/
...
images/project-08/

Replace the placeholder JPG filenames with your actual screenshots.
Keep the filenames listed in index.html, or edit the projectData array.

Recommended images per project:
1. Main screenshot
2. Supporting screenshot
3. Detail screenshot
4. Result / additional screenshot

The gallery opens as a floating modal with:
- Large main project image
- Two secondary preview cards
- Thumbnail strip
- Previous / Next controls
- Keyboard arrow navigation
- ESC to close
- Responsive mobile layout
